## 1. 假說與先驗

### 1.1 假說

**H1**：在 Binance USDT 永續上，價格掃過「未被掃過的擺動極值」（停損聚集區）
後隨即收回、且該次掃單的主動成交流被吸收（或伴隨 CVD 背離）時進場反轉，
其淨期望報酬顯著為正，且顯著優於匹配隨機進場。

### 1.2 先驗聲明（**混合，且含一條方向相反的實證**）

本案的先驗**明顯優於 M**（M 是「基於成分證偽的高信心負向先驗」），但**不是**單純正向：

**支持面**
- Osler (2003, *J. Finance* 58(5); FRBNY Staff Report) 用真實外匯委託單簿證實：
  **停損單確實聚集在近期高低點之外**，獲利了結單聚集在整數關卡。
  「擺動極值外側有流動性池」這個前提**有直接的委託單簿證據**，不是民俗學。
- 吸收（大量主動單被靜止的反向掛單吃掉而價格不動）是有明確微觀結構機制的現象：
  大型知情交易者需要對手方才能建立部位，掃停損正是製造對手方的手段。

**反對面（必須正視——這是最強的反面證據）**
- **Osler 的實證結論方向與本案敘事相反**：她發現停損被觸發造成的是**價格續勢
  （cascade）**，不是反轉；反轉發生在**獲利了結單**聚集處。
  換言之，「掃前高 → 反轉」在她的資料上應該表現為「掃前高 → 續漲」。
- M 的 verdict 已在同一批幣、同一段期間證實：**幾何式的「反轉區」概念
  劣於隨機進場 2.26 倍**（逆選擇）。若 sweep 只是換一種畫「反轉區」的方式，
  它有很高機率重蹈覆轍。
- M2 的消融顯示，加在 1h K 線上的量能類過濾器（成交量 z ＋ 主動單方向）
  在曝險校正後是 **−0.063R/事件**，全表最差之一。

### 1.3 判別性預測（預註冊，**這是本案最有資訊量的設計**）

上述張力給出一個**可事前宣告、可證偽**的判別：

| 若真實機制是… | sweep-only 臂應該… | 加吸收過濾後應該… |
|---|---|---|
| **Osler 的停損串聯** | 顯著**續勢**（反轉方向為負） | 無改善或惡化 |
| **吸收/知情交易者建倉** | 接近 0 或弱負 | **顯著轉正** |
| **兩者皆非（噪音）** | 與隨機無異 | 與隨機無異 |

因此 **N-G8（§8）** 專門檢定「吸收是否帶來邊際貢獻」。
**即使 G2/G3 通過，若 sweep-only 已經同樣好、吸收無邊際貢獻，
verdict 必須揭露「吸收機制未獲支持」**，不得把功勞歸給訂單流。

**已實地驗證的四項事實**（2026-08-09，主對話實跑；抓取層檔頭亦記載）：

1. **符號約定**：`is_buyer_maker = True` → 掛單方是買方 → **主動方是賣方** → `sign = −1`。
   **跨源對帳**：GALAUSDT 2023-03-15 00:00 UTC 那根 1h 棒，aggTrades 算得的主動買量

2. **header 行在 2022-08 中旬才出現**，且 daily 與 monthly 切換點不同步。

3. **行數 ≠ 成交筆數**（aggTrades 是聚合的，實測 GALA 同日差 3.4 倍）。

4. 每個 `.zip` 旁有 `.zip.CHECKSUM`（SHA-256），一律校驗。

## 4. 事件定義：流動性掠奪（sweep）

### 4.1 流動性池 P

以 `scripts/m_detect.find_pivots(df, L)`（既有、已驗證因果性）取得擺動極值。
`Pivot.confirm_t` 已是**收盤時間**（`t + bar_ms − 1`），可直接與 `as_of` 比較。

- **primary**：`L = 10`，entry interval = `1h`。
- 池 P 於 `confirm_t(P) ≤ close_t(j−1)` 時才可用（**不得用尚未確認的 pivot**）。

### 4.2 「未被掃過」

pivot high `P`（形成於 bar `i`）在 bar `j` 之前**未被掃過**，若
`∀ k ∈ (i, j): high[k] ≤ P`。pivot low 鏡像（`low[k] ≥ P`）。

### 4.3 掃單事件

**空方掃單**（掃前高，預期反轉向下 → **做空**），於 bar `j`：

```
∃ 未被掃過的 pivot high P，confirm_t(P) ≤ close_t(j−1)
且  high[j] >  P          （針刺穿池）
且  close[j] < P          （同棒收回池內 ＝ 假突破）
```

**多方掃單**（掃前低 → **做多**）鏡像：`low[j] < P` 且 `close[j] > P`。

`as_of = close_t(j)`。最早可成交時點為 bar `j+1` 的開盤。

**凍結的設計選擇（無自由參數）**

| 選擇 | 決定 | 理由 |
|---|---|---|
| 最小穿刺幅度 | **無門檻**（任何超越皆算） | 門檻是自由旋鈕；M 的教訓是容差旋鈕買到勝率但買不到 E[R]。穿刺幅度分布列為強制揭露。 |
| 收回時限 | **同棒收回** | 「N 棒內收回」會引入 N 這個旋鈕。 |
| 一根棒掃到多個池 | 取**最近的**（價格上離 close 最近） | 固定規則，不挑選。 |
| 同時符合多空 | 不可能（同棒不能既 `close<P_high` 又 `close>P_low` 於同一池）；若不同池各觸發一次，**各自成事件** | 與 M 的多形態處理一致，重疊度列為揭露。 |

## 5. 訂單流特徵（**全部無自由參數**）

全部由 aggTrades 計算，取值範圍嚴格 `≤ close_t(j)`。以 USDT 計價
（`notional = price × quantity`），使跨幣可比。

令掃單棒 `j` 內的成交集合為 `T_j`，`sign = +1`（主動買）／`−1`（主動賣）。

### 5.1 掃單腿 delta（`D_sweep`）

空方掃單（池為 pivot high `P`）：

```
D_sweep = Σ_{t ∈ T_j, price(t) ≥ P}  sign(t) × notional(t)
```

即**價格在池之上那段時間內的帶號主動成交額**。多方掃單鏡像（`price(t) ≤ P`）。

### 5.2 吸收確認（**ABS**）

```
空方掃單：ABS 成立 ⟺ D_sweep > 0
多方掃單：ABS 成立 ⟺ D_sweep < 0
```

語意：**主動買方把價格推上池之上（停損被觸發／突破買盤進場），
但價格收回池內** → 那些主動單被靜止的賣單吸收了。

> **僅取符號、不設幅度門檻**——這是刻意的：幅度門檻是自由參數，會推高試驗數，
> 且 M 的教訓是這類旋鈕買到的是勝率不是期望值。`|D_sweep|` 與
> `D_sweep / V_sweep` 的分布列為強制揭露，供未來預註冊使用。

### 5.3 CVD 背離確認（**DIV**）

令 `CVD_n = Σ_{k ≤ n} D_k`（自該 symbol 資料起點累加的逐棒 delta）。

```
空方掃單：DIV 成立 ⟺ CVD_j ≤ CVD_{i(P)}
多方掃單：DIV 成立 ⟺ CVD_j ≥ CVD_{i(P)}
```

其中 `i(P)` 是池 P 形成的那根棒。語意：**價格創了比 P 更高的高點，
但累積主動買盤沒有同步創高** → 上行缺乏成交流支撐。

### 5.4 缺值處理

任一特徵無法計算（該 symbol-month 的 aggTrades 缺檔、或棒內零成交）
→ **該事件整筆排除**，並計入 `n_dropped_nodata` 揭露。
**兩臂同規則**（§7），故不引入偏差。

## 6. 進出場與記帳

### 6.1 進場

**bar `j+1` 的開盤，市價（taker）**。不模擬 Stop 單——1h K 線無棒內路徑，
假設「觸發價即成交價」是樂觀偏差且無法從本資料驗證（沿用 M2 的 P11 裁決）。

### 6.2 停損：針尖外側

```
做空：SL = high[j] × (1 + b)
做多：SL = low[j]  × (1 − b)
b = 0.0011  （= 1 × round-trip taker：2 × (TAKER 0.00045 + SLIP 0.0001)）
```

`b` **由凍結的成本常數導出**，非依結果調校。理由：緩衝小於單趟往返成本時，
該停損在經濟上不可執行。

### 6.3 停利：對側未被掃過的流動性池

```
做空：於最近 N_POOLS = 20 個已確認的 pivot low 中，
      取【未被掃過】且【低於進場價】者中【最接近進場價】的一個作為 TP。
做多：鏡像（pivot high、高於進場價）。
```

`N_POOLS = 20`：搜尋窗必須有界（否則 TP 可能落在數年前的價位、與當下結構無關），
20 是「涵蓋近期結構但不回溯過遠」的固定選擇，於本 spec 凍結，**不作為可調檔位**
（本值與 M2 報告中使用過的 `MTF_N_LEVELS` 相同，屬巧合性的沿用，非依賴）。
**若無符合者 → 終局 `no_target`，`R_net = 0`，計入分母**（比照 M 的 `no_fill`）。

> **強制揭露**：此處的「未清算流動性池」是**結構定義**（未被掃過的擺動極值），
> 不是字面意義的未平倉部位——USDT 永續沒有歷史清算資料（§3.3）。

### 6.4 風險距離退化守門

```
若 |fill − SL| / fill < MIN_RISK_FRAC = 0.0022 → 終局 risk_too_small，R_net = 0，計入分母
```

推導：`MIN_RISK_FRAC = 2 × round-trip taker = 2 × 2 × (0.00045 + 0.0001) = 0.0022`。
低於 1× 時光成本就吃掉 1R，該筆在任何方向上都不可能有正期望，故 1× 是硬下界、
2× 留最小餘裕。由凍結成本常數導出，非依結果調校。
**不得靜默剔除**——靜默剔除等於只砍輸單，會使結果偏樂觀（M2 的 B2 教訓：
未設此守門時，單筆 `R_net` 曾達 −5.79e12，兩筆就污染整格均值）。

### 6.5 出場掃描與終局

自 fill 棒起，最多 `MAX_HOLD = 100` 根（沿用 M）。棒內優先序 **SL → TP（悲觀）**，
SL gap-through 取開盤（較差），TP 恆取 TP 價（沿用 M spec §4.5）。

**終局（互斥窮盡，皆須有 `term_t`）**：
`tp` / `sl` / `time_stop` / `censored` / `no_target` / `risk_too_small` /
`invalidated_by_gap`（開盤已穿 SL）/ `nodata`。

### 6.6 成本與 R-multiple

兩腿皆 taker：`fee = TAKER + SLIP = 0.00055`／腿。沿用 `m_backtest.r_net_single`
（已有 spec 錨例，不重寫）。壓力測試 `STRESS_MULT = 1.5`。

## 7. 匹配隨機對照組（**M2 的教訓事前內建**）

### 7.1 生成

僅為**通過該格全部條件的事件**生成對照（含訂單流過濾），
`K = 5`，`δ ∈ [MAX_HOLD + 1, 300]` 正向位移，價格以 `close` 比值平移，
每事件 RNG 由 `sha256(SEED:event_id)` 決定性派生。沿用 `m_control.make_controls`。

### 7.2 對照臂必須通過**完全相同**的條件

對照事件在**它自己的 `as_of`** 上求值全部過濾器（含 ABS/DIV）。
兩臂呼叫**同一個函式物件**，並由測試斷言（`FILTER_ENTRYPOINT is ...`），
使公平性成為結構保證而非記憶。

### 7.3 曝險必須對齊（**預註冊的硬性檢查**）

> M2 的 B5 事故：對照臂的加權曝險曾達形態臂的 1.19–7.52 倍，
> 兩臂皆負 EV 時，逐日配對差會**機械性轉正**——6 個「優於隨機」的正號死了 5 個。

**本案事前規定**：

1. 每個母事件的存活對照，權重**重新正規化為合計恰好 1**。
2. **曝險比**（對照臂加權曝險 ÷ 事件臂事件數）必須落在 **[0.95, 1.05]**，
   否則該格**宣告作廢**，不得解讀。此檢查寫入 gate 引擎，機械執行。
3. **主要統計量是「每事件 E[R]」，不是日報酬均值**——日報酬與交易頻率相依，
   跨格比較無效（M2 §2-B5）。日報酬序列僅用於揭露。

### 7.4 自助法

以 **symbol 為叢集**重抽（尊重同幣事件的相依性），`B = 10000`，
種子由 `(SEED, gate_id)` 派生（沿用 `m_stats.gate_rng`）。

## 8. 預註冊 GO / NO-GO gate

| Gate | 判準 | 不過的意義 |
|---|---|---|
| **N-G0** 資料對帳 | 抽樣 ≥ 200 個 symbol-hour，aggTrades 主動買量與 kline `takerBuyVolume` 相對誤差 < 1e-9 | 資料層有誤，全案作廢 |
| **N-G1** 無前視 | 偵測層與回測層截斷式斷言全綠（比照 `tests/test_m_nolookahead.py`）；訂單流特徵亦須通過 | 有前視，全案作廢 |
| **N-G1b** 曝險對齊 | 各格曝險比 ∈ [0.95, 1.05] | 該格作廢，不得解讀 |
| **N-G2** 絕對期望 | `lower_95(E[R]/event) > 0`（全期） | 不可部署，不論 G3 |
| **N-G3** 優於隨機 | `lower_95(Δ E[R]/event) > 0`（全期） | sweep 不優於隨機進場 |
| **N-G4** 試驗數校正 | `psr ≥ 0.95`（OOS，`n_trials = N_TRIALS_DECLARED`） | 與運氣無法區分 |
| **N-G5** 時間樣本外 | OOS `lower_95(E[R]) > 0` | 時間衰退 |
| **N-G6** 幣種樣本外 | holdout 半數幣 `lower_95(E[R]) > 0` | 幣種依賴 |
| **N-G7** 成本壓力 | 費率 ×1.5 後 `lower_95(E[R]) > 0` | 成本吃掉 edge |
| **N-G8** 機制判別 | `lower_95(E[R]_{sweep+ABS} − E[R]_{sweep_only}) > 0` | **吸收無邊際貢獻**——見下 |

### 8.1 判定表（機械導出，無裁量）

| 狀態 | 判定 |
|---|---|
| G0 或 G1 不過 | **作廢**（重做資料層／偵測層） |
| G2 不過 | **NO-GO**（絕對期望為負，不論 G3） |
| G2 過、G3 不過 | **NO-GO**（sweep 不優於隨機——與 M 同一結局） |
| G2、G3 過，G4/G5/G7 任一不過 | **NO-GO** |
| 全過、**G8 不過** | **GO（但機制未獲支持）**——verdict 必須揭露「edge 來自 sweep 結構本身，吸收無邊際貢獻」，且不得宣稱訂單流是 edge 來源 |
| 全過且 G8 過 | **GO** |

### 8.2 G8 的方向性解讀（§1.3 的判別性預測）

- `E[R]_{sweep_only} < 0` 且 `E[R]_{sweep+ABS} > 0` → **支持吸收機制**（本案的核心假說）。
- `E[R]_{sweep_only} > 0` 且 ABS 無增益 → edge 來自 sweep 結構，**吸收敘事不成立**。
- `E[R]_{sweep_only}` 顯著為負且反轉方向為負（即掃後續勢） → **支持 Osler 的停損串聯**，
  本案假說方向錯誤；此時應考慮**反向**（順掃單方向）的新預註冊，而非調參。

## 11. 風險與限制（verdict 必須逐條複述）

1. **「吸收」是成交流推論，非掛單簿觀測**（§3.3）。真正的 resting liquidity 拿不到。
2. **「未清算流動性池」是結構定義**，非字面未平倉部位。USDT 永續無歷史清算資料。
3. **Osler (2003) 的實證方向與本案敘事相反**（§1.2）——這是最強的先驗反面證據。
4. 本案與 M/M2 使用**同一批幣、同一段期間**的 K 線。雖然假說與特徵完全不同，
   但該資料的「樣本外乾淨度」已被前兩案消耗，G4 的校正只涵蓋本案宣告的 40 個試驗。
5. aggTrades 是**聚合**成交，非逐筆原始成交（`trades` 資料集才是）；
   本案的 delta 因此是聚合層的，微小的筆數層資訊不可得。
6. pilot（4 幣 × 6 月）**統計力不足以判定任何 gate**，僅供資料層驗證。
7. 進場恆為 taker、兩腿皆付 taker 成本——這是誠實但保守的假設；
   真實執行若能部分以 maker 成交，結果會較好，但本案不宣稱該優勢。
8. 15m 檔位的 aggTrades 計算量約為 1h 的 4 倍；若因成本未跑滿網格，
   須在 verdict 揭露實跑格數並據此重算 `sr*`。
